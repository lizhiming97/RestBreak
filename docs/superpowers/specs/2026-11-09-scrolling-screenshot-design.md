# 长截图（滚动截图）设计

日期：2026-11-09。用户确认：自己滚动；拼好后和普通截图一样可复制/保存/贴图/标注/提取文字/翻译；参考 Snow Shot（mg-chao/snow-apps，GPL-3.0，C++/Qt/Rust）的交互，**只参考思路，不复制代码**（截图在 MIT 主程序内）。

## 用户路径

1. 两个入口：
   - 截图框选后，工具栏新增「长截图」按钮（`rectangle.expand.vertical`）。
   - 新全局快捷键 `ShortcutAction.scrollingCapture`（默认不设置，放在设置「截图」页）：按下后进入框选，框选松手即直接进入长截图。
2. 进入长截图：定格画面撤掉，选区四周保留 2pt 蓝色描边（不可点击、鼠标穿透），旁边浮动控制面板：已拼长图缩略图、当前高度（像素）、提示文字、「完成」「取消」。
3. 用户用滚轮/触控板/方向键在目标区域里往下滚，星期五截选区、拼接，缩略图实时变长。
4. 「完成」或 Enter：打开长图预览窗口；Esc 或「取消」：放弃。
5. 完成时提示一次「拼接偶尔会漏行，分享前看一下开头、中间和结尾」（参考 Snow Shot 文档）。

## 采集

- 截屏：ScreenCaptureKit `SCScreenshotManager` 截选区所在显示器的选区矩形，排除星期五自己的窗口（描边、控制面板）。沿用现有录屏权限，不需要辅助功能。
- 时机：只在长截图期间工作。`NSEvent.addGlobalMonitorForEvents(.scrollWheel)` 记下最后一次滚动时间，停止约 100ms 后截一张；另有 0.25 秒兜底计时器（接住惯性滚动和方向键/翻页键），画面与上一帧相同则丢弃。结束即移除监听和计时器。
- 选区所在屏幕变化、显示器变化、休息开始：取消长截图（与现有截图一致）。

## 拼接（纯函数 `Engine/ScrollStitcher.swift`，单测覆盖）

输入：上一帧、新帧（同尺寸灰度行数据）。

1. **固定区识别**：从顶部逐行比较两帧，相同的连续行为顶部固定区（导航栏）；底部同理。固定区不足帧高 40% 才认定，否则视为画面没动。
2. **位移匹配**：在中间区域，用行哈希（每行降采样后的灰度和 + 差值签名）找新帧相对上一帧向上移动的行数 `dy`；候选位移内取匹配行比例最高者，要求 ≥ 90% 且重叠 ≥ 中间区高度的 15%。
3. 结果：
   - `dy > 0`：把新帧中间区底部 `dy` 行接到长图（固定区顶部只在第一帧保留一次；底部固定区在完成时补到最后）。
   - `dy == 0`：无变化，丢弃。
   - 向上滚（匹配到负位移）：丢弃，提示「往回滚的内容不会重复拼接」。
   - 找不到重叠：丢弃，提示「滚得太快了，往回滚一点」。
4. 上限：长图高度 30000 像素，到达后自动停止采集并提示。

## 长图预览窗口（`UI/LongImageWindow.swift`）

- 普通可调大小窗口，内容为可上下滚动的长图（宽度适配窗口，超过时缩放显示）。
- 复用 `AnnotationEditor` + `AnnotationToolbar`：宿主为预览窗口里的图像视图（实现 `AnnotationHost`），坐标为图像坐标，滚动时标注跟随。
- 工具栏动作与普通截图一致：复制、保存（`ImageExport`）、贴图（`PinWindow`，超过屏幕高度时按屏幕缩放）、提取文字、翻译、关闭；Enter/⌘C、⌘S、Space、Esc 快捷键一致。
- 提取文字对长图按段识别（每段 ≤ 4000 像素高，结果按顺序拼接）。

## 代码边界

- `Engine/ScrollStitcher.swift`：拼接算法，无 UI 依赖。
- `App/ScrollingCaptureSession.swift`：采集计时、监听、截屏、调用拼接、状态（帧数、高度、提示）。
- `UI/ScrollingCapturePanel.swift`：描边窗口 + 控制面板。
- `UI/LongImageWindow.swift`：预览与标注。
- `ScreenshotController`：新增 `.scrollingCapture` 动作与快捷键入口，结束后恢复前台 App。
- `CaptureAction` 增加 `.scroll`；`ShortcutAction` 增加 `.scrollingCapture`（`isScreenshot` 为 true）。

## 不做

横向长截图、自动滚动、录屏。自动滚动以后可借「星期五鼠标」组件发滚轮事件。

## 测试

自动：拼接算法用合成图覆盖——正常下滚、顶部固定栏、底部固定栏、上下都有、往回滚、无重叠、无变化、到达高度上限、单色区域（无法判定时不拼）。其余为 UI，靠真机。

真机（用户）：网页（含固定导航栏）、聊天记录、代码编辑器、触控板惯性滚动、快捷键入口、完成后标注/贴图/提取文字。
