# 截图 + 贴图（第一期）设计

日期：2026-10-21　状态：已确认

## 目标
在「歇一会」里加入轻量、快捷、美观的截图和贴图。只用苹果系统框架，不引入第三方库。标注、OCR、翻译留到后续阶段。

## 入口
- 两个全局快捷键（默认都不设置）：**截图**、**贴剪贴板**。不加菜单栏菜单项。
- 设置侧边栏在「快捷键」前新增「截图」分组（图标 `camera.viewfinder`）：
  - 录屏权限卡片：状态（已允许 / 未允许）+「打开系统设置」按钮；设置窗口每次回到前台时刷新。
  - 快捷键卡片：截图、贴剪贴板（与现有录制框同一套）。
  - 选项卡片：截图时显示放大镜（开关，默认开）、贴图默认透明度（滑条 20%～100%，每档 10%，默认 100%）。
- 「快捷键」页只显示休息相关的 3 个快捷键，截图相关的只在「截图」页显示。

## 交互

### 1. 发起
- 按截图快捷键 → 0.1 秒内把所有屏幕定格（ScreenCaptureKit），每块屏幕盖全屏窗口，选区以外压暗约 40%。
- 没有录屏权限：第一次调用系统授权弹窗；之后弹我们的小窗说明，带「打开系统设置」和「重新打开歇一会」按钮。
- 休息遮罩显示中快捷键无效；截图中再次按下无效。

### 2. 悬停（未框选）
- 鼠标下的目标蓝框高亮，**单击**选中该目标；**拖动**自由框选（不能跨屏，以起点所在屏为准）。
- 可识别目标，优先级从高到低：菜单栏右侧单个图标（电量、Wi-Fi、时间、其他 App 图标）→ 展开的菜单 → 菜单栏空白处（整条菜单栏，含刘海两侧）→ 普通窗口（含已有贴图）。不识别桌面和 Dock。
- 选区可以覆盖整块屏幕，包括最上方菜单栏。
- 放大镜（可在设置里关）：光标旁约 8 倍像素网格 + 坐标 + 颜色值，按 C 复制颜色（#RRGGBB）。
- `Esc` 或右键：取消并关闭。

### 3. 松手后（调整）
- 8 个控制点调大小，拖内部移动；左上角显示 `640×360`（像素）。
- 方向键移动 1 像素，`⇧`+方向键调大小 1 像素（右/下边），最小 1×1。
- 选区下方出现工具栏（下方放不下放上方，都放不下放选区内底部）：`📌 贴图  ⬇ 保存  ✕ 取消  ✓ 复制`。
- 快捷键：`Enter` / `⌘C` 复制，`Space` 贴图，`⌘S` 保存，`Esc` 或右键清除选区回到悬停状态。
- 复制后显示 1 秒「已复制」小提示。

### 4. 保存
系统保存框，默认文件名「截图 2026-10-21 15.30.12.png」，记住上次目录。取消回到选区；保存失败弹系统提示，选区保留。

### 5. 贴图
- 无边框置顶窗口，圆角 + 柔和阴影，按原图 100% 大小贴在截取的位置，所有桌面空间可见。比屏幕大时缩小到屏幕 80% 以内。
- 拖动移动（始终保留一部分在屏幕内），双击或 `Esc` 关闭，`⌘C` 复制。
- `⌥`+滚轮调透明度（20%～100%），初始值取设置里的默认透明度。
- 右键菜单：复制 / 保存… / 透明度 ▸（100/80/60/40%）/ 关闭 / 关闭所有贴图。
- 贴剪贴板快捷键：剪贴板有图片则贴在鼠标位置；只有文字则渲染成白底深字卡片（最宽 480pt，自动换行，超长截断加「…」）；都没有则系统提示音。
- 退出 App 后贴图不保留，数量不限。休息遮罩在贴图之上。

## 技术方案
- 定格再框选：按下快捷键时 `SCScreenshotManager` 截每块屏幕，框选结果从定格图里裁剪（按各自屏幕的像素密度）。
- 框选界面用 Core Animation 图层：定格图作为图层内容只设置一次；压暗层是带镂空的 `CAShapeLayer`（even-odd）；放大镜是取同一张图局部、`magnificationFilter = .nearest` 的小图层。鼠标移动只改几个图层属性。外层 `NSView` 负责鼠标、光标、键盘。
- 预热：启动时创建好框选窗口并隐藏，按快捷键只做截图 + 显示。
- 工具栏、贴图右键按钮：macOS 26 用 Liquid Glass（`glassEffect`），macOS 14～15 退回 `.ultraThinMaterial`。
- 目标识别用 `CGWindowListCopyWindowInfo`（按截图那一刻读一次）：layer 0 普通窗口、主菜单栏层、状态栏图标层、弹出菜单层。

## 系统快捷键冲突（作用于全部 5 个快捷键）
- 数据来源：优先 `CopySymbolicHotKeys` 读本机实际启用的系统快捷键（已关闭的不算）；读不到时用内置列表兜底：⌘⇧3/4/5 及加 ⌃ 的剪贴板版本、⌘Space、⌃Space、⌃⌥Space、⌘Tab、⌃↑↓←→、⌃⌘Q、⌃⌘Space、⌘⌥D 等，每项带中文名。
- 录制时冲突：不保存，录制框保持录制状态，下方显示「⚠ 与系统「将所选区域截屏」冲突，按下时只会触发系统功能」和「仍然使用」「重新录制」按钮。
- 注册失败（被其他 App 占用）沿用现有红字，文案改为「已被其他 App 占用，请换一个」。

## 异常处理
| 情况 | 处理 |
|---|---|
| 截图失败 | 提示音 + 「截图失败」小提示，不进入框选 |
| 截图中休息开始 | 立即取消截图 |
| 截图中显示器插拔 | 取消截图 |
| 复制/保存/贴图/取消后 | 恢复之前的前台 App |

## 测试
- `CaptureGeometryTests`：各方向拖动、限制在屏幕内、8 个控制点命中、方向键微调与最小尺寸、重叠目标取最上层且按优先级、菜单栏图标优先于菜单栏、工具栏下/上/内、1×/2× 点像素换算、默认文件名。

- `AppSettingsTests`：缺少截图字段的旧设置文件能读出默认值。
- 快捷键页面过滤：`isScreenshot` 分组正确。
- `xcodebuild` 编译通过，现有全部测试（含 20 天模拟）通过。
- 手动验收：权限流程、单/双屏、Retina 清晰度、菜单栏图标/菜单/整条菜单栏识别、各操作、贴图右键菜单、剪贴板文字卡片、系统快捷键冲突提示。
