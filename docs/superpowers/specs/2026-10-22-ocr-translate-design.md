# 截图 OCR + 翻译（第三期）设计

日期：2026-10-22　状态：已确认　前置：第一期、第二期截图设计

## 决定
- OCR 用系统 Vision（离线、无需下载、无新权限）。
- 翻译用**腾讯云机器翻译 TextTranslate**（用户选择：系统翻译语言包太大）。国内服务器约 0.2～0.5 秒；文本翻译每月 500 万字符免费，后付费默认关闭。用户在设置里填自己的 SecretId / SecretKey，存钥匙串。

## 入口
- 框选工具栏右端操作组新增「提取文字」(`text.viewfinder`) 和「翻译」(`translate`)，作用于带标注的选区图片。提取文字：关闭框选，弹文字面板；翻译：弹面板并直接翻译。
- 贴图右键菜单新增「提取文字」。

## 文字面板（浅色浮窗，置顶、可拖动，出现在选区附近）
- 上：识别出的原文（可编辑）；按 Vision 行重建排版：同一行的多段用两个空格连接，行距明显大于行高时插入空行分段。没识别到文字时显示「没有识别到文字」。
- 中（翻译后出现）：「译文 · 中 → 英」，点标题切换方向；方向自动判断：汉字占字母类字符一半以上 → 英文，否则 → 中文。
- 下：「N 行 · N 字」+「翻译」「复制原文」「复制译文」。Esc 或 ✕ 关闭。
- 翻译状态：翻译中… / 失败原因（没联网、没设置密钥（带「去设置」）、密钥不对、免费额度用完、未开通服务、请求太频繁、其他附错误信息）。

## 设置（「截图」页新增「翻译」卡片）
- SecretId、SecretKey 输入框（SecretKey 密文显示），「保存」「测试」（翻译「你好」显示结果）、「如何申请」链接（腾讯云控制台 API 密钥页）。

## 技术
- `Engine/OCRLayout.swift`：行 → 文本（纯逻辑）。
- `Engine/TencentTranslateProtocol.swift`：TC3-HMAC-SHA256 签名、请求、响应和错误码解析、按 2000 字分段、方向判断（纯逻辑，CryptoKit）。
- `Services/TextRecognizer.swift`（Vision，后台执行）、`Services/TencentTranslator.swift`（URLSession，分段依次请求，密钥存钥匙串）。
- `UI/TextResultPanel.swift`：面板窗口 + SwiftUI 内容。
- 测试：签名中可公开验证的部分对照腾讯官方示例（payload 哈希、规范请求哈希）；HMAC 用 RFC 4231 向量；响应/错误码解析；分段；方向；排版；渲染文字图片后真实 OCR。

## 不做
原位翻译（译文覆盖在原图上）、其他翻译服务、自动复制识别结果。
