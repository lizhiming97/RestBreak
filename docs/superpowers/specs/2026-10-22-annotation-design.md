# 截图标注（第二期）设计

日期：2026-10-22　状态：已确认　前置：`2026-10-21-screenshot-pin-design.md`

## 目标
在第一期的框选界面上直接标注，复制 / 保存 / 贴图得到带标注的图片。只用系统框架。

## 工具栏（浅色，替换第一期的深色工具栏）
```
╭───────────────────────────────────────────────╮
│ □ ○ ↗ ✎ ▍ T ▦ ① │ ↶ ↷ │ 📌 ⬇ ✕ ✓ │
╰───────────────────────────────────────────────╯
     ╭──────────────────────────────╮
     │ · • ● │ 🔴🟠🟡🟢🔵⚫⚪ │   ← 属性条：选了工具或选中了标注才出现
     ╰──────────────────────────────╯
```
- 图标全部 SF Symbols，17pt regular、单色 #3A3A3C：`square` `circle` `arrow.up.right` `pencil.tip` `highlighter` `textformat` `checkerboard.rectangle` `1.circle` │ `arrow.uturn.backward` `arrow.uturn.forward` │ `pin` `square.and.arrow.down` `xmark` `checkmark`。
- 按钮 32×32，间距 4；分组之间 18pt 高细分隔线。悬停浅灰圆角底；选中工具蓝 #3D7BF7 图标 + 淡蓝圆角底；✓ 恒为蓝色；不能撤销/重做时灰掉。
- 条：浅色圆角（10）。macOS 26 浅色 Liquid Glass；14～15 白色 95% + 0.5pt 灰边 + 柔和阴影。
- 属性条：主工具栏下方、左对齐。粗细 3 档（三个由小到大的圆点）；颜色 7 个 16pt 实心圆点（红 橙 黄 绿 蓝 黑 白），选中加蓝圈。马赛克的颜色区换成「像素块 / 模糊」；文字的粗细档表示字号。
- 每个工具记住自己的颜色和粗细（存进设置，重启后保留）；默认红色、中号、像素块。

## 交互
- 点工具选中，再点一次取消；数字键 1～8 对应 8 个工具（编辑文字时除外）。
- **不选工具**：选区仍可移动、调整大小（同第一期）；已画的标注留在原位置（标注按屏幕坐标存）。
- **选了工具**：在选区内拖动即绘制，选区控制点隐藏；标注裁剪在选区内。选区外的点击不画。
- 工具：

| 工具 | 操作 |
|---|---|
| 矩形 / 椭圆 | 拖动画框；⇧ 正方形 / 正圆 |
| 箭头 | 从起点拖到终点，箭头在终点；⇧ 吸附 45° |
| 画笔 | 自由画线，中点二次曲线平滑 |
| 荧光笔 | 半透明（40%）、粗、正片叠底；一笔内重叠不加深；⇧ 画直线 |
| 文字 | 点一下就地输入；Enter 换行，Esc 或点别处结束；空文字不保留；描边保证可读（白/黄字用深色描边，其他用白色描边） |
| 马赛克 | 拖一个矩形，里面按原图像素打码；属性条选像素块或模糊；粗细档决定块大小 / 模糊程度 |
| 序号 | 点一下放实心圆 + 白色数字，编号 = 现有最大编号 + 1；删除不重排 |

- **改已有标注**：选了任何工具时，点在已有标注上 = 选中它（虚线框），拖动移动，⌫ 删除，属性条改颜色/粗细（同时成为该工具的默认值），双击文字重新编辑。点空白处取消选中并开始新的绘制。不支持拖控制点改大小。
- ⌘Z 撤销、⌘⇧Z 重做，覆盖画、移动、删除、改样式、改文字。
- Esc 依次：结束文字编辑 → 取消选中标注 → 取消选中工具 → 清除选区（有标注时需 1 秒内连按两次，第一次提示「再按一次 Esc 放弃标注」）→ 退出截图。右键同 Esc。
- 复制 / 保存 / 贴图得到「选区 + 标注」合成图；贴图是合成后的图片，不能再编辑。

## 技术方案
- `Engine/Annotation.swift`（纯逻辑，单元测试）：`AnnotationTool`、`AnnotationColor`（含 RGB）、`StrokeSize`、`MosaicStyle`、`ToolStyle`、`Annotation`（id、工具、点、样式、文字、文字尺寸、编号）；⇧ 约束、包围框、点击命中（线条按到线段的距离，框按边，马赛克/文字/序号按区域，取最上面的）、移动、下一个编号、各工具的实际线宽/字号/块大小；`AnnotationDocument`：快照式撤销/重做，拖动移动用 begin/update/commit 一次计入撤销。
- `UI/AnnotationRenderer.swift`：唯一的绘制代码。`drawComposite(in:size:selection:source:scale:annotations:cache:)` 先画选区底图再画标注；屏上标注图层和导出都调用它，保证「看到的 = 得到的」。马赛克用 Core Image（`CIPixellate` / `CIGaussianBlur`）处理原图对应像素，按 id + 位置 + 样式缓存。
- `UI/AnnotationToolbar.swift`：SwiftUI 主工具栏 + 属性条，`AnnotationToolbarModel`（ObservableObject）驱动。
- `UI/CaptureOverlay.swift`：有标注时显示标注图层（选区大小，画底图 + 标注）；选中标注的虚线框是单独的 `CAShapeLayer`，不进导出；文字编辑用临时 `NSTextField`；`selectedImage()` 返回合成图。
- `Engine/AppSettings.swift`：`annotationStyles: [AnnotationTool: ToolStyle]`。改样式时经 `ScreenshotController` 回调写回设置。

## 测试
- `AnnotationTests`：⇧ 约束、命中、移动、删除、改样式、撤销/重做（含拖动只记一次）、编号、样式默认值与旧设置兼容。
- `AnnotationRendererTests`：导出图尺寸为选区像素；红色矩形边上是红色、内部是原图；马赛克区域像素被改变；文字区域有非底色像素；空标注时导出等于原图裁剪。
- 现有全部测试通过。
