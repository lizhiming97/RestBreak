# 贴身管家：从第一性原理重新梳理

日期：2026-10-24　状态：待确认　替代：`2026-10-23-butler-scenarios.md` 里「场景库」「版本安排」两节（感知信号清单、隐私原则仍然有效）

## 目标
你一天大部分时间对着电脑，投入工作时会忘事。歇一会要做你的 **24 小时贴身管家**：它留意你的状况，**在该开口的时候主动来找你**。不只是执行你吩咐过的提醒，你没交代过的事，只要值得，它也会来说。

### 闹钟和管家的区别
| | 闹钟（0.5 已有的） | 管家（要做的） |
|---|---|---|
| 谁决定什么时候开口 | 你，或 AI 替你定好时间 | 管家自己判断 |
| 依据 | 时钟 | 时钟 + 日历 + 你在做什么 + 你说过的话 + AI 任务的状态 |
| 典型的话 | 「21:00 吃药」 | 「评审 10:30 开始。你昨天说要带转化数据，那张表还没打开过」 |

## 管家为什么来找你：五种来意
场景不按领域分（健康 / 工作 / 生活），否则会越列越乱。只按「为什么是现在」分，一共五种。每种对应灵动岛上的一个颜色和来意文字（`IslandIntent`）。

| 来意 | 意思 | 例子 | 颜色 |
|---|---|---|---|
| **到点了** | 你交代过的事，时间到了 | 吃药、交房租、下班买牛奶 | 茶绿（强提醒为琥珀） |
| **快来不及了** | 再不行动就晚了 | 会议 5 分钟后开始；答应中午前发的报价单还没发；还款日是明天 | 天蓝 |
| **你可能忘了** | 有件事悬着，你像是没顾上 | Codex 跑完 12 分钟没看；上午说要回的邮件到下午还没动；AI 在等你批准 | 茶绿 |
| **你该停一停了** | 身体或节奏需要照顾 | 11:30 后一直没离开电脑；连开 3 个会；23:00 还在工作 | 玫红 |
| **值得让你知道** | 不用马上做，但你该知道 | 开工时的今日安排；下班前的收尾清单；周五的一周小结 | 琥珀 |

**每一次推送都只回答三件事：什么事、为什么是现在、点一下能做什么。** 说不清「为什么是现在」的，就不推。

## 架构：感知 → 判断 → 推送
```
            ┌──────────── 感知（歇一会 App，全在本机）──────────────┐
            │ 时钟 · 日历 · 离开/开会/全屏 · 前台 App · 休息统计     │
            │ AI 任务状态（hooks）· 你让 AI 记下的事（notes）       │
            └───────────────┬──────────────────────┬───────────────┘
                            │ 读（MCP: get_context） │ 读
              ┌─────────────▼───────────┐   ┌──────▼──────────────────┐
              │ 判断①：内置规则（App）  │   │ 判断②：你的 AI 定时巡视 │
              │ 要准点、不能错的事       │   │ 要「想一想」的事          │
              │ 提醒到点、会前 5 分钟、   │   │ 每 30～60 分钟一次，      │
              │ 午饭、加班、AI 等你批准  │   │ 结合它对你的了解来判断    │
              └─────────────┬───────────┘   └──────┬──────────────────┘
                            │                      │ 写（MCP: push）
              ┌─────────────▼──────────────────────▼──────────────────┐
              │ 推送（App）：打扰预算 → 去重 → 时机（开会/全屏先等）   │
              │ → 灵动岛                                               │
              └────────────────────────────────────────────────────────┘
```
- **App 仍然不接任何模型，也不需要 API Key。** 要「想一想」的事，交给你已经在用的 AI 去想。
- **判断① 内置规则**：要求准点、不能依赖 AI 是否在线的事，由 App 写死的规则负责。
- **判断② 定时巡视**：
  - 在 Claude 的定时任务或 Codex 的自动化里设一个「管家巡视」任务，你本机已有 `~/.codex/automations`。
  - 每次巡视，AI 先调用 `get_context` 看现状，再结合它对你的了解（记忆、最近的对话），判断有没有值得推送的事；有，就调用 `push`。
  - 巡视的说明由歇一会生成，你在设置里复制一下就能装好。
- **推送**统一走同一个出口。不论来自规则还是 AI，都要经过打扰预算、去重、看时机这几关，再显示到灵动岛。

### 新增的 MCP 工具
| 工具 | 作用 |
|---|---|
| `get_context` | 管家视角的现状。包括：现在几点、星期几；今天的日程（只有标题和时间）；你是否在开会、全屏、离开电脑及其时长；今天连续工作了多久、休息完成几次、跳过几次；AI 任务状态；接下来的提醒；记下的事（notes）；今天已经推过什么、还剩多少打扰预算 |
| `push` | 推送一条。参数：`intent`（五种来意之一）、`title`、`why`（为什么是现在）、`primaryAction`（如「打开日程」「去看看」「知道了」）、可选 `snoozeMinutes`、`dedupeKey`（同一件事不重复推）。返回推了、排队了，或因为预算、去重被拦下及原因 |
| `remember` / `forget` | 记下 / 删掉值得管家知道的事，比如承诺、截止、在吃的药、最近的身体状况。带有效期和来源，你都能在设置里看到和删除 |

### 打扰预算（防止管家变烦）
- 管家主动推送的「快来不及了」「你可能忘了」「该停一停了」「值得让你知道」，**每天最多 8 条**。你自己交代的「到点了」不占预算。
- 同一件事（`dedupeKey`）一天只推一次。同一种来意 30 分钟内最多一条。
- 开会、全屏、专注 App、休息中：先等，最多 30 分钟；等不到的，并进下一次「值得让你知道」。
- 每条推送都可以点「少提醒这类」，记两次就停掉这一类推送，可以在设置里恢复。

## 内置规则（不靠 AI，第一批）
| 规则 | 来意 | 触发 |
|---|---|---|
| 提醒到点 | 到点了 | 0.5 已有 |
| 会前 5 分钟 | 快来不及了 | 日历里下一个会还有 5 分钟，且你不在开会 |
| AI 在等你批准超过 3 分钟 | 你可能忘了 | Claude Code / Codex 的 `PermissionRequest` hook |
| AI 任务跑完 10 分钟你还没回去 | 你可能忘了 | `Stop` 之后那个终端或 App 一直不在前台 |
| 午饭 | 该停一停了 | 11:30～13:30 之间没离开超过 15 分钟，13:00 时推 |
| 连续工作太久 | 该停一停了 | 连续工作 90 分钟且跳过了最近一次长休息 |
| 太晚了 | 该停一停了 | 22:30 后还在用电脑（每晚一次） |
| 开工 / 收工 | 值得让你知道 | 当天第一次开始用电脑；下班时间后第一次长时间离开前（汇总今天剩下的事） |

## 版本安排（替代原来的 0.6～0.8）
- **0.6 管家骨架**：
  - 推送出口（预算、去重、时机）+ `IslandIntent` 全部五种；
  - `get_context`、`push`、`remember`、`forget`；
  - 设置里新增「管家」：推送记录（推过什么、为什么）、打扰预算、「少提醒这类」的管理、复制巡视任务说明；
  - 内置规则：会前 5 分钟、午饭、太晚了、开工与收工。
- **0.7 接上 AI 工作感知**：Claude Code / Codex hooks（原设计第 8 节），以及规则「AI 等你批准」「AI 跑完你没回去」；额度信息并入 `get_context`。
- **0.8 管家更懂你**：
  - 承诺追踪：AI 在聊天里听到「我下午发给他」就 `remember`，快到期时由巡视推送；
  - 「连续工作太久」规则；
  - 一周小结；
  - 节假日和调休。

## 不做
- App 自己调用大模型。
- 读你的聊天记录、浏览器、剪贴板、屏幕内容。日程只取标题和时间。
- 手机端。

## 已确认（2026-10-26）
1. 打扰预算：每天 8 条（「到点了」不占）。
2. AI 巡视：约 45 分钟一次。
3. 0.6 的内置规则只做「开工 / 收工」；会前 5 分钟、午饭、太晚了先不做。「AI 等你批准」「AI 跑完没看」在 0.7。

## 0.6 实现时的调整（2026-10-26）
1. 「少提醒这类」点一次就屏蔽该来意（设计写的是两次），设置里可全部恢复。
2. 打扰预算、屏蔽的来意、下班时间存在 store 的 `butler.prefs`，不在 `AppSettings`：小程序 `push` 时也能当场判断。
3. 0.6 的 `push` 不支持「点了打开某个链接」，主按钮只表示收到。
