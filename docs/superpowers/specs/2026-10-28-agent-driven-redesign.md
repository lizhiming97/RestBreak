# 提醒与管家改版：App 只做「嘴」，Agent 做「脑子」

日期：2026-10-28　状态：已确认（版本 0.7）　替代：`2026-10-24-butler-v2-design.md` 里「判断① 内置规则」「remember / forget」「0.7 AI 工作感知」三部分；`2026-10-23-agent-reminders-design.md` 里「安装」一节

## 一句话
歇一会只负责**在合适的时候把话递到你眼前**。说什么、什么时候该说，由你主要在用的那个 Agent（Claude、Codex、WorkBuddy……）想好再推过来。歇一会对外是一个标准的 MCP，接入只需要一次「复制给你的 AI」。

## 用户的原话（2026-10-28）
- 会用多个 Agent，但主要用一个；每个人习惯不同，所以接入要标准，同意 MCP。
- App 只用来做消息提醒（一个窗口）；想对用户说的内容，由主要用的 Agent 去思考，像定时刷新的自动化任务。
- App 要做的：提供 MCP 接入，让用户傻瓜操作，「复制给你的 Agent」就能接上；该提醒的时候主动提醒。
- 可以扩展 Agent 思考的方向，自定义更多场景。
- **明确的到点指令**（如「21:00 吃药」）留在 App 里：Agent 的定时任务不保证准点（合盖、Agent 没开、额度用完），这类事由 App 自己按时弹。

## App 保留什么、删掉什么

| 部分 | 现在 | 改版后 | 理由 |
|---|---|---|---|
| 到点提醒（单次/每天/间隔/每月/每年、强提醒再提醒、错过汇总、系统通知兜底） | 有 | **保留** | 用户明确要求；必须准点，不能依赖 Agent 在线 |
| `push`（现在推一条） | 有 | **保留** | Agent 巡视后开口的唯一出口 |
| 打扰预算、去重、开会/全屏/休息中先等 | 有 | **保留** | 这是「怎么说」不是「说什么」：防止 Agent 推得太多、推得不是时候 |
| `get_context`（现状） | 有，另有 `get_overview` 和它重复 | **合并成一个** | 少一个让 Agent 犹豫的工具 |
| 灵动岛 | 有 | **保留** | 就是那「一个窗口」 |
| 内置开工、收工推送规则 | 有 | **删除** | 这是 App 在「想」该说什么，交给 Agent |
| `remember` / `forget`（管家记事本） | 有 | **删除** | 记住用户的事是 Agent 自己的记忆该做的，App 再存一份会两边不一致 |
| hooks 感知 AI 工作状态、额度（原 0.7 计划） | 只有第 0 步留下的 `HookEvent`、`UsageParser`，没接入 | **删除，0.7 不做** | Agent 自己知道自己的任务状态；「跑完没看」可以由 Agent 巡视时推 |
| 按客户端分开的三套安装（Claude Code 插件、Codex TOML、Claude Desktop JSON） | 有 | **换成两段复制**：接入方式、巡视任务说明 | 新 Agent 不用等 App 适配；定时由用户在自己的 AI 应用里设 |
| 「关注方向」（让 Agent 想什么） | 写死在巡视说明里 | **新增设置**，由 `get_context` 带给 Agent | 用户可扩展场景，改了不用重新复制 |

## 工具（从 9 个减到 6 个）
| 工具 | 作用 | 要不要每次批准 |
|---|---|---|
| `get_context` | 现在几点、星期几；在不在电脑前、开会、全屏、休息中；今天的日程（标题和时间）；连续工作多久；接下来的到点提醒；**用户设的关注方向**；今天推过什么、还剩几条预算 | 不用（只读） |
| `push` | 现在推一条：来意、标题、为什么是现在、主按钮、去重标识。被拦下时返回原因 | 不用（有预算兜底） |
| `create_reminder` | 建一个到点提醒（只在用户明确说了时间时用） | 每次问 |
| `list_reminders` | 列出到点提醒和完成情况 | 不用（只读） |
| `update_reminder` | 改、暂停、恢复 | 每次问 |
| `delete_reminder` | 删 | 每次问 |

工具说明里写清分工：**用户说了明确时间的事用 `create_reminder`；巡视时自己判断出来的事用 `push`，不要为了「过一会再说」去建提醒。**

## 接入：两段复制，定时由用户自己设（2026-10-28 用户补充）
现在的 AI 应用（Codex 的「设置定时任务」、Claude 的 Routines 等）都自带定时任务，重复、时间、模型由用户在那里自己设。歇一会**不替用户建定时任务、不规定间隔**，只提供两段文字：

**① 接入歇一会**（按钮「复制接入方式」）
一段说明 + 配置，用户可以自己贴进 Agent 的配置，也可以直接发给 Agent 让它自己配：
> 请把「歇一会」（我 Mac 上的提醒 App）加到你的 MCP 配置里：名字 `xieyihui`，类型 stdio，命令 `<小程序路径>`，不需要参数和环境变量。只读工具 `get_context`、`list_reminders` 和 `push` 可以设为免批准。加好后调用一次 `get_context` 确认能用。以后我说「几点提醒我做什么」时，用 `create_reminder` 建在歇一会里。
>
> 通用配置：`{"mcpServers":{"xieyihui":{"command":"<小程序路径>"}}}`

- 各家配置格式不同，但每个 Agent 都知道自己的配置怎么改，App 不用为每家写模板，也不碰别的 App 的文件（沙盒也不允许）。
- 下面一个收起的「Codex 配置」小链接，给需要手动贴 TOML 的情况。原来的 Claude Code 插件方式删除。

**② 巡视任务说明**（按钮「复制任务说明」）
用户在自己 AI 应用的定时任务里新建一个任务，把这段贴进「说明 / Instructions」，重复和时间自己选（页面上建议每 30～60 分钟一次）：
> 你是我的贴身管家，现在做一次例行巡视。
> 1. 调用歇一会（xieyihui）的 get_context，看我现在的状况、今天的日程和提醒、我希望你留意的方向、还剩几条推送预算。
> 2. 按「留意的方向」，结合你对我的了解（记忆、最近的对话），判断现在有没有值得主动跟我说的事：快来不及的事、我可能忘了的事、我该停一停的时候、值得知道的事。
> 3. 有就调用 push（每次最多 1～2 条），title 说什么事，why 说清为什么是现在；没有就什么都不做。说不清为什么是现在的，不要推。
> 4. 不要给我发消息、不要问我问题，巡视完直接结束。

- 和旧版相比去掉了「管家记下的事」和 remember / forget：记住用户的事交给 Agent 自己的记忆。
- 说明里只写「怎么巡视」，「留意什么」由 `get_context` 实时带过去，所以用户改了关注方向**不用重新复制**。

**其他**
- 「连接状态」卡片保留（已连接：Codex / Claude Code …，最后使用时间），用来确认真的接上了。
- 开发版（从 Xcode 运行，路径在 DerivedData）照旧在底部提示「换到正式安装位置后需要重新复制」。

## 关注方向（新）
设置「提醒 › 管家」页改为「关注方向」：
- 一组常用场景的开关，默认开前三个：
  - 快开会了还没准备（会前 5～10 分钟）
  - 你答应过的事快到期了
  - AI 任务跑完 / 在等你批准，你还没看
  - 连续工作太久、该吃饭了、太晚了还在工作
  - 开工时的今日安排、收工前的小结
- 一个「我还想让它留意……」的多行输入框，用户用自己的话写，比如「周五下午提醒我写周报」「看到我连续开三个会就提醒我喝水」。
- 打扰设置保留：每天最多主动推几条（预算）、最近推送列表（可看「为什么推」，可点「少提醒这类」）。
- 删掉「下班时间」设置（收工规则删了；Agent 想推收工小结，可以从关注方向里读到用户写的下班时间）。

这些写进 App Group 的 store（`butler.prefs`），`get_context` 原样返回：`focus: { presets: [...], custom: "..." }`。

## 已知限制（要在页面上说清）
- Agent 不支持本机 stdio MCP 的，接不上（比如只能连云端 URL 的客户端，包括 Claude Desktop 的「自定义连接器」）。WorkBuddy 等是否支持，接入时实测。
- Agent 不支持定时任务的，只能用到点提醒和你主动让它推的消息，不会自己巡视。
- 本地定时任务只在电脑醒着、联网时运行（Claude Routines 页面原话），合盖期间不会巡视。
- 巡视的频率、准不准时，取决于 Agent 的定时任务；只有到点提醒由 App 保证。
