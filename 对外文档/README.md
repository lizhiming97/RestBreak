# 星期五（原名「歇一会」，RestBreak）· 对外文档

这是我从零做出来的一款 macOS 菜单栏小工具的介绍和复盘。它一开始叫「歇一会」，0.7 起改名「星期五」；下面几篇写于改名前，沿用旧名。一开始它只是一个提醒我休息的闹钟，六天后，它会避开会议、读日历、截图标注、识字翻译，还能让我的 AI 助手替我建提醒。

这些文档用我自己的口吻写，尽量不讲行话。想快速了解，看第一篇就够了；想知道过程和难点，往后看。
