# 星期五鼠标组件（验证版）

基于 Mos 的平滑滚动核心，为普通离散滚轮提供平滑、上下/左右反向、速度、平滑程度、最小步长和应用排除。macOS 14+，独立非沙盒 App；星期五主程序仍为沙盒。许可 CC BY-NC 4.0，来源和修改见 [UPSTREAM.md](UPSTREAM.md)。

## 使用

1. 使用包含本组件的星期五包，进入「设置 → 鼠标 → 打开鼠标设置」。也可把 `星期五鼠标.app` 放在星期五旁边。
2. 为「星期五鼠标」授权辅助功能，回到组件点「重试」，开启「鼠标增强」。默认关闭；原生方向默认保留。
3. 分别设置上下/左右反转和平滑。速度、平滑程度、最小步长默认使用所选 Mos 源码版本的值。
4. 对不适合的应用添加排除项。关闭「鼠标增强」立即释放输入拦截并停止惯性输出。

检测到正式或 Debug 版 Mos 运行时不接管滚轮，先退出 Mos 后重试。其他鼠标驱动仍可能干预滚动；本版保守跳过已连续化的事件，Magic Mouse 和触控板保持原样。

星期五托管时不新增菜单栏图标，星期五退出时组件也退出。单独打开组件时有自己的菜单栏入口；退出组件恢复原生滚动。曾打开过鼠标设置后，星期五下次启动会尝试拉起组件；组件只有启用过才继续运行。

## 构建

```sh
swift test --build-system native --package-path MouseCompanion
python3 MouseCompanion/scripts/build_app.py --build-friday
```

在仓库根目录运行，产物在 `MouseCompanion/dist/`。完整构建从 Xcode 主程序签名提取身份，用同一身份签组件及组合包；保留主 App 原有 entitlements。可显式指定 `--identity`。只有单独构建组件且未指定身份时默认 ad-hoc，供本地开发，不等于公证。

已有 CC 集成版主程序时，可使用 `--main-app /绝对路径/星期五.app`；主程序须已包含鼠标设置入口。脚本保留包内其他 Helpers，新增鼠标组件，再重新签名。不会安装或启动成品。

## 范围

合成帧以原事件目标 PID 投递；拿不到目标时原样放行。点击、鼠标移动、修饰键变化、切换 App/桌面时清掉惯性。锁屏、睡眠、退出或关闭时停表并销毁 event tap；权限撤销或系统禁用监听时停止，用户点重试恢复，不无限自动重启。

DisplayLink 只在滚动时运行；开启功能时有每 5 秒一次的健康检查。不是零开销。高刷新率、Magic Mouse、Logi 驱动和真实应用手感需要设备验证。诊断和验证边界见 `../docs/mouse/2026-11-03-validation.md`。
